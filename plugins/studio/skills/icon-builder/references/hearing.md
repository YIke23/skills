# ヒアリング

アイコンは差し替えコストが高い。ブラウザのキャッシュは残り、LINE公式アカウントは
1時間に1回しか変更できず、決まった瞬間から名刺・スライド・SNSに波及していく。
描き始める前にここを埋める。

## 必ず聞く

| 項目 | なぜ聞くか |
|---|---|
| **参考にしたいアイコン**（URL・スクショ・「◯◯みたいな」） | 言葉より速い。3つ挙げてもらうと方向が一気に定まる |
| **既存のロゴ・シンボルの有無**（SVGがあるか） | あるなら流用が最善。無いなら意匠から起こす |
| **名前と、アイコンに載せる文字**（頭文字1〜2字か、記号か） | 3文字以上は16pxで確実に潰れる。ここで止める |
| **ブランドカラー**（HEX） | 明るいタブと暗いタブの両方で3:1を確保できるか事前に判定できる |
| **使う面**（Webだけ / PWA / アプリ） | `--targets` が決まる。作らない面の議論を省ける |
| **サイトの技術**（Next.js / Nuxt / Laravel / WordPress / 素のHTML） | `--framework` が決まる。分からないなら「サイトのURL」を聞いて推測する |

## 余裕があれば聞く

- **避けたい方向**（「ITっぽすぎるのは嫌」「和のニュアンスを残したい」）— 却下理由は好みより情報量が多い
- **同業他社で被りたくない相手** — 形が衝突していないか確認できる
- **暗い背景で使う場面があるか**（ダークモードのサイト、黒いスライド）— 反転版の要否
- **将来アプリを出す可能性** — あるなら最初からAndroidの安全域を意識して描くと後で作り直さずに済む

## 何も出てこないとき

「参考が思いつかない」と言われたら、**方向性の軸を2〜3組見せて選んでもらう**のが速い。

- 頭文字のモノグラム / 事業を表す抽象記号 / 具体物のシルエット
- 塗りのプレート型（角丸の四角に白抜き） / 透過の図案型
- 幾何学的で硬い / 手描きで柔らかい

このスキルの `preview_icons.py` は候補を並べて比較させるためのものなので、
**迷ったら方向性の違う3案を実際に描いて見せたほうが早い。** 言葉での擦り合わせより、
16pxのプレビューを1回見せるほうが決まる。

## 決まったら確認する

- 「この形で、タブの中ではこう見えます」と原寸プレビューを見せてから確定する
- 「ホーム画面では四隅が丸く切られます」を先に伝える。後から気づかれると作り直しになる
- **SNSでも使う予定があるなら、そのことだけ確かめておく。** 書き出しは `sns-icon-builder`
  の担当だが、円と角丸四角の両方で切られると分かっていれば、四隅に情報を置かない意匠を選べる
